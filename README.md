# TSENEX Bank Collector Releases

TSENEX 법인계좌 수집기 자동 업데이트용 공개 배포 저장소입니다.

- 프로그램 소스코드는 공개하지 않습니다.
- 공동인증서, 암호, API 키, 계좌 설정과 은행 거래 데이터는 포함하지 않습니다.
- Windows 실행파일은 [GitHub Releases](../../releases)에서 제공합니다.
- 각 ZIP 파일은 함께 제공되는 SHA-256 체크섬으로 검증할 수 있습니다.

## 설치 및 업데이트

1. 최신 Release의 `TSENEX-Bank-Collector-win-x64.zip`을 내려받습니다.
2. 같은 Release의 `.sha256` 파일로 무결성을 확인합니다.
3. 기존 설치 폴더에 압축을 풉니다.
4. 설치 후에는 프로그램의 `업데이트 확인` 버튼으로 새 버전을 설치할 수 있습니다.
